### Product APIs

---

Description: Retrieve all products.
Method: GET
URL: `/api/products/all`
JSON Example:
Response:
```json
[
  {
    "pID": 1,
    "p_name": "Engine Oil 10W-30",
    "categoryID": 101,
    "price": 25.50,
    "current_stock_quantity": 150,
    "supplierID": 10
  },
  {
    "pID": 2,
    "p_name": "Brake Fluid DOT4",
    "categoryID": 102,
    "price": 12.75,
    "current_stock_quantity": 200,
    "supplierID": 11
  }
]
```

### Sales APIs

---

Description: Create a new sale.
Method: POST
URL: `/api/sales/create`
JSON Example:
Request:
```json
{
  "customerID": 101,
  "productSales": [
    {
      "productID": 1,
      "quantity": 2,
      "unitPrice": 25.50
    },
    {
      "productID": 2,
      "quantity": 1,
      "unitPrice": 12.75
    }
  ],
  "totalAmount": 63.75,
  "paymentMethod": "Cash"
}
```
Response:
```json
{
  "saleId": 1001,
  "customerID": 101,
  "saleDate": "2026-09-28",
  "productSales": [
    {
      "productID": 1,
      "quantity": 2,
      "unitPrice": 25.50
    },
    {
      "productID": 2,
      "quantity": 1,
      "unitPrice": 12.75
    }
  ],
  "totalAmount": 63.75,
  "paymentMethod": "Cash"
}
```
*Note: The actual `CreateSaleRequest` DTO structure would be needed for a precise request example. I've inferred a common structure for sales creation.*
